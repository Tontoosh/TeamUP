# Үүрэгт суурилсан хамтрагчийн санал

`role-weighted-v1` нь төслийн нээлттэй үүрэг бүрд хүнийг үнэлнэ.
Тохирлын оноо амжилттай хамтрах магадлал биш. Эхлэх жингүүдийг бодит
хамтын ажиллагааны үр дүнд тулгуурлан дараа нь тохируулна.

## Ашиглах

1. Профайл засах → ур чадвар бүрийн өөрийн үнэлгээг 1–5 түвшнээр сонгоно.
2. Төсөл үүсгэх/засах → үүрэг бүрийн skill, доод түвшин, ач холбогдол,
   цаг болон заавал биелүүлэх шаардлагыг сонгоно.
3. Төслийн “Тохирох хамтрагч олох” эсвэл “Танд санал болгох” хэсгийг нээнэ.
4. Картын “Яагаад санал болгосон бэ?” хэсгээс онооны задаргааг харна.
5. Ажил дуусвал эзэмшигч “Төсөл дуусгах” үйлдлийг баталгаажуулна.
6. Тухайн үед багт байсан гишүүний профайлд ажлын чанар, хугацаа/хариуцлага,
   харилцааны 1–5 үнэлгээ болон сэтгэгдэл өгнө.

Элсэлт хаах нь ажил дуусгахтай адил биш. Архивлахад өмнө дууссан төслийн
үнэлгээ өгөх эрх хадгалагдана. Дууссан төслийн мэдээлэл, гишүүний үүрэг,
чат зөвхөн унших горимтой болно.

## Тооцоолол

Нийт оноо = 60 × skill + 20 × цаг + 10 × сонирхол + 10 × үнэлгээ.
Хэсэг бүрийг 0–1 хооронд тооцно.

- Skill: үүргийн шаардлага бүрийн `min(хүний түвшин / доод түвшин, 1)`
  утгыг ач холбогдлын 1–5 жингээр дундажлана. Хамааралгүй skill оноо нэмэхгүй.
- Профайлд skill байгаа ч түвшин тодорхойгүй бол `0.5 / доод түвшин`
  хэсэгчилсэн оноо өгнө. Заавал шаардлагатай түвшнийг энэ нь хангахгүй.
- Цаг: `min(боломжит цаг / шаардлагатай цаг, 1)`.
- Сонирхол: төслийн ангилал профайлын сонирхолд байвал 1, бусад үед 0.
- Үнэлгээ: `(Bayesian үнэлгээ − 1) / 4`.

Bayesian үнэлгээ = `(n × дундаж + 5 × 4) / (n + 5)`.
Суурь үнэлгээ 4/5, суурь жин 5. `n` нь ялгаатай үнэлэгчдийн тоо.
Нэг гишүүний олон төслийн үнэлгээг эхлээд дундажлаж нэг санал болгоно.
Үнэлгээгүй хүн 4/5 суурьтай; түүнийг эрэмбээс хасахгүй.
Сэтгэгдлийн өнгө аясыг автоматаар оноонд хувиргахгүй.

Блоклосон, идэвхгүй, аль хэдийн тухайн багт байгаа хүнийг санал болгохгүй.
Нээлттэй, сул суудалтай төслийн үүргүүдийг ашиглана. Заавал шаардах skill/цаг
хангаагүй хүнийг тухайн үүрэгт санал болгохгүй. Олон үүрэг/төсөл тохирвол
хамгийн өндөр оноотой тохирлыг харуулна. Ижил оноонд ID-аар тогтвортой эрэмбэлнэ.
Эдгээр босго нь автомат саналд хамаарна; нэгдэх хүсэлтийг эзэмшигч шийднэ.

## Өгөгдөл ба эрх

Шинэ хүснэгтүүд `CREATE TABLE IF NOT EXISTS` / SQL Server-ийн ижил нөхцөлөөр
нэмэгдэнэ. Хуучин users/projects мөрүүдийг дахин бичихгүй. Хуучин skill түвшнийг
таамгаар бөглөхгүй; тохиргоогүй үүргүүд төслийн skill болон цагаар уян хатан
анхны шаардлага үүсгэнэ.

Төсөл дуусахад багийн бүрэлдэхүүний snapshot хадгална. Тэр snapshot-д
хоёулаа байсан хүмүүс л үнэлгээ өгнө. Өөрийгөө үнэлэх, бусдын нэрээр үнэлэх,
нэг төсөлд давтан үнэлэхийг API болон unique constraint-аар хориглоно.
Үнэлгээ, сэтгэгдэл засах/устгах API байхгүй. Нууцлагдсан төслийн үнэлгээг
нийтийн профайл болон эрэмбэд ашиглахгүй.

SQLite-ийн шинэчлэл, хадгалалт, API эрх, алгоритм болон browser урсгалууд
тесттэй. SQL Server-ийн шинэ хүснэгт, source overlay-г кодоор дэмжсэн;
амьд SQL Server холболтоор шинэ урсгалыг баталгаажуулаагүй.

## API

- `PATCH /api/users/me`: `skillLevels: [{ skill, level }]` нэмэгдсэн.
- `POST/PATCH /api/projects[/id]`: `roleRequirements` нэмэгдсэн.
- `GET /api/users/owned-projects`: тохирол хайж болох өөрийн төслүүд.
- `GET /api/users/people?project=…&role=…`: тухайн үүргээр эрэмбэлэх.
- `GET /api/users/recommendations`: хүн/төслийн санал, онооны задаргаа.
- `POST /api/projects/:id/status`: `completed` шинэ төлөв.
- `GET /api/reviews/:userId`: үнэлгээ, нэгтгэл, үнэлж болох төслүүд.
- `POST /api/reviews`: project_id, target_id, quality, reliability,
  communication, comment; author_id-ийг session-оос авна.
